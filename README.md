# narrow-tuner-kit

DevOps engineer · Python and boto3

处理日常小任务的工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/narrow-tuner-kit.git
cd narrow-tuner-kit
chmod +x run.sh
```
